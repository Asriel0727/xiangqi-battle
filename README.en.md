🎮 Click the move link below to play the game (using GitHub Issue)  
👥 Everyone can participate, red and black take turns to move!

## How to move?

1.  Click a location link in the table (such as`a2-a3`)
2.  The system will automatically create an Issue containing movement instructions.
3.  Submit the Issue directly to complete the move
4.  Return to this page to view the latest chessboard situation (if the chessboard is not updated, please wait a few seconds or refresh the page)
